# Architecture

```text
Vue 3 frontend
  -> FastAPI HTTP/SSE endpoints
  -> request middleware: request id, auth, rate limit, error shape
  -> Agent router
  -> Tool functions
  -> MetricService
  -> SQLAlchemy models
  -> MySQL or SQLite local demo
  -> text response or VISUAL_PAYLOAD for ECharts
```

## Production Guardrails

- Deterministic business metrics stay in `MetricService`.
- Model output is optional and only polishes Tool results.
- `VISUAL_PAYLOAD` is generated by backend code, not free-form model text.
- Auth mode keeps the existing `sa-token` frontend contract.
- Liveness and readiness are separate: `/healthz`, `/readyz`, `/actuator/health`.
