# 学生作业评分标准

总分 100 分。

| 项目 | 分值 | 标准 |
|---|---:|---|
| 能跑起来 | 20 | 前后端、MySQL、Redis、AI 调用链路可运行 |
| 读懂主链路 | 20 | 能解释 Chat、Agent、Tool、Service、Repository 的关系 |
| 完成一个小改造 | 25 | 新增一个指标、工具或图表问题，并保持主流程可用 |
| 自检和测试 | 20 | 能运行 smoke check、Maven test 或前端 build，并说明结果 |
| 代码讲解 | 15 | 能在 3 分钟内讲清楚自己改了哪些文件、为什么这样改 |

## 不合格情况

- 项目无法启动。
- 直接让大模型编造经营指标，没有走 Java 工具或数据库。
- 改动范围过大，导致原有演示问题失效。
- 提交 API Key、数据库密码等敏感信息。

## 推荐提交内容

```text
1. 修改文件列表
2. 新增功能说明
3. 运行截图或输出
4. 自检结果
5. 遇到的问题和解决方法
```
