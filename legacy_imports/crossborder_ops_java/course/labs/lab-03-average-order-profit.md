# Lab 03：新增一个业务指标

## 目标

理解并复现一个简单但真实的经营指标，让学生练习从 Service 到 Tool 再到 Agent 的最小改造。

注意：当前仓库是完整演示版，主源码已经包含“平均订单利润”。本 Lab 的目标是看懂它应该如何实现，并在 starter 版本、删除已有实现后的本地副本，或课堂练习分支中完成同样改造。

## 推荐题目

理解“平均订单利润”：

```text
平均订单利润 = 毛利润 / 订单数
```

## 修改位置

| 文件 | 改什么 |
|---|---|
| `CrossBorderMetricService.java` | 经营概览结果里如何计算平均订单利润 |
| `OrderAnalyticsTool.java` | 工具输出文本里如何展示平均订单利润 |
| `SalesAgentSmokeTest.java` | 如何用最小断言确认输出包含该指标 |

## 实施步骤

1. 先看 `CrossBorderMetricService` 里经营概览结果对象或输出结构。
2. 找到订单数和利润已经在哪里计算。
3. 只在已有计算结果上加一行除法，不新增表。
4. 订单数为 0 时返回 0，避免除零。
5. 在工具输出中确认或追加：

```text
平均订单利润
```

6. 运行：

```powershell
cd backend
mvn test
```

## 指标口径

```text
平均订单利润 = 毛利润 / 订单数
```

本 Lab 不扣除退款、广告费或物流费；这些口径可以作为挑战题讨论。

## 验收标准

- 原有经营概览还能正常回答。
- 新输出包含“平均订单利润”。
- 没有为了这个指标新增复杂类、配置或依赖。

## 加分项

让前端快捷问题里出现：

```text
分析最近30天的平均订单利润
```

## 任务分层

- 必做：能指出后端经营概览在哪里输出“平均订单利润”，并能在练习版本中复现。
- 进阶：加一个快捷问题入口。
- 挑战：说明这个指标是否应该扣除退款和广告费用。

## 提交物

1. 修改后的后端代码。
2. 新增或修改的测试代码。
3. 一次经营概览返回结果，包含“平均订单利润”。
4. `mvn test` 运行结果。
5. 200 字以内说明：这个指标的公式和口径。
