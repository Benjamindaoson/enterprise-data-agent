# Lab 04：新增一个图表问题

## 目标

让学生理解结构化图表 payload，而不是让大模型自由生成前端代码。

## 任务

新增一个经营图表问题：

```text
生成最近30天退款金额趋势图
```

完成后，用户在前端发送这个问题时，应该看到退款金额折线图。

## 修改位置

| 文件 | 改什么 |
|---|---|
| `VisualPayloadTool.java` | 增加退款金额趋势的 payload 输出 |
| `CrossBorderMetricService.java` | 如果已有数据方法可复用，直接复用；没有再加最小查询 |
| `frontend/src/views/ChatView.vue` | 增加一个快捷问题按钮 |
| `frontend/src/components/ChartRenderer.vue` | 只在必要时改，优先复用已有图表类型 |

## 实施原则

- 优先复用现有 `line` 图表。
- payload 仍然以 `VISUAL_PAYLOAD:` 开头。
- 前端不解析自然语言中的数字。
- 不新增图表库。

## 建议步骤

1. 先读 `VisualPayloadTool.java` 里现有经营趋势图怎么生成。
2. 再读 `CrossBorderMetricService.java`，确认退款数据是否已有可复用方法。
3. 写一个最小测试或接口自检，先证明当前没有退款金额趋势图。
4. 在后端生成 `VISUAL_PAYLOAD:`，图表类型用 `line`。
5. 在 `ChatView.vue` 增加快捷问题。
6. 跑后端测试和前端构建。

## 自检问题

```text
生成最近30天退款金额趋势图
```

## 验收标准

- Agent 能正确识别退款趋势问题，并调用对应 Tool。
- Tool 参数能表达时间范围，进阶版本支持店铺名称。
- 退款金额来自数据库，不由模型生成。
- 后端返回统一 `VISUAL_PAYLOAD:` 图表 payload。
- 前端出现折线图。
- 图表标题和坐标轴语义正确。
- 无数据时不会报错。
- 原有净销售额和利润趋势图不受影响。

## 提交物

1. 修改后的后端代码。
2. 修改后的前端代码。
3. 一张退款金额趋势图截图。
4. 一个测试问题及返回结果。
5. `mvn test` 和 `pnpm build` 运行结果。
6. 200 字以内说明：退款金额的数据来自哪张表，以及为什么要用结构化 payload。

## 任务分层

- 必做：实现退款金额折线图。
- 进阶：把快捷问题加入前端。
- 挑战：支持按店铺筛选退款趋势。
