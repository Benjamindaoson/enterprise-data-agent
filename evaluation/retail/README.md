# Retail adversarial holdout v1

This directory contains the frozen holdout for `RetailAdversarialBench-v1`.

- 84 cases total.
- 14 adversarial categories.
- 6 cases per category.
- The runtime module does not generate this file.
- Future implementation changes must not rewrite holdout questions to fit the code.
- Any intentional holdout revision requires a new versioned file and benchmark version.

The public development split contains 168 additional cases, giving 252 total questions.
